# Provisional validation data

These files contain local measurements collected while integrating automatic
transcript viewport rendering. Background game activity affected the machine
during this work. Performance validation was paused at the user's request, and
these results are not an acceptance decision or a reliable performance comparison.

Do not treat these timings as release claims. Repeat the controlled headless and
PTY comparisons when benchmarking is explicitly resumed. The imported experiment's
results remain separate under bench/.
